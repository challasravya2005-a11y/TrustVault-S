# TrustVault-CS 🔒

A secure document-sharing platform featuring Role-Based Access Control (RBAC) and real-time audit logging built with Node.js.

## Features
- **User Authentication:** Login and session handling using HTTP cookies.
- **Role-Based Access Control (RBAC):** Restricts document visibility based on user roles (`Admin` vs `Regular User`).
- **Real-Time Audit Trail:** Logs authentication events and access actions automatically.
